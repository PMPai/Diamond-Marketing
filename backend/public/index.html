工作流程說明

建立項目後，系統依序執行六個分析階段；實際進度與報告請到該項目的詳情頁查看。

01 / INFORMATION

資訊收集

整理公司、產品與市場的基礎資料。

02 / INSIGHTS

深度分析

從已收集資料辨識問題與機會。

03 / GOAL

優先目標

形成可供後續策略使用的目標與衡量方式。

04 / INITIATIVE

溝通策略

規劃對應目標的營銷行動與溝通方向。

05 / IMPLEMENTATION

執行建議

整理執行任務、工具與時程建議。

06 / MASTER

彙總報告

彙整各階段的分析結果與建議。

以上為標準流程，不代表任何項目已完成；若某階段資料不足，請以項目詳情中的實際狀態為準。
